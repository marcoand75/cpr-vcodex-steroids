# CPR-vCodex Steroids — Home Themes (Lyra Marcoand75)

> **SCOPE:** LyraMarcoand75Theme — carousel home screen with cover flow, data panels, frame cache, cover generation integration.

---

## 1. User-Facing Functionality

| Feature | Description |
|---------|-------------|
| **Carousel Navigation** | Center cover + left/right previews, swipe/buttons to navigate |
| **Data Panels** | Progress bar, reading time, session count, streak badge per book |
| **Recent Books** | Up to 10 recent books (configurable) |
| **Cover Cache** | Persistent frame cache (~48 KB/frame) for instant redraw |
| **Cover Generation** | On-demand thumbnail generation with placeholder fallback |
| **Shortcuts Grid** | 7-slot pageable shortcuts (Apps, Settings, etc.) |
| **Sleep Screen Preview** | Cover shown on sleep screen |

### 2.4 Cover Generation Integration
```cpp
// CoverGenerator.cpp
// Triggered by: single-book delete, page delete, book open
// Pipeline:
// 1. Heap guard check (ESP.getMaxAllocHeap() > minimum)
// 2. Parse EPUB/XTC/TXT for cover image
// 3. Generate thumbnail: thumbPathFor(path, w, h) → /thumbs/<hash>_<WxH>.bmp
// 4. Dithering: Atkinson, 4-level grayscale
// 5. Progressive: one cover per frame, requestUpdate()

// Collection tiles: never generated by grid
// queryCollections()/queryMixed() scan for first book with existing thumb
// If none → placeholder with white-title black ribbon
```
