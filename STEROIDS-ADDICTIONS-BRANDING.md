## 3. Web Server Pages

### 3.1 `HomePage.html` (Root `/`)
- Steroids branding header
- Device status (battery, storage, version)
- Navigation: Flash, Settings, Stats Editor, Tools
- Ko-fi link (marcoand75)

### 3.2 `flash.html` (`/flash`)
- Auto-flash firmware from latest GitHub release
- **Defaults to X4** (rejects X4 Pro regardless of metadata)
- Progress bar, status messages
- Steroids branding

### 3.3 `SteroidsSettingsPage.html` (`/settings`)
```html
<!-- Sections: -->
<!-- 1. Sleep Screen: mode, cover mode, cover filter, clean refresh -->
<!-- 2. Library: layout, filter, sort, view mode, update mode -->
<!-- 3. Power Button: short press action, long press action -->
<!-- 4. Reading Stats: import/export, manual correction -->
```
- GET `/api/steroids-settings` → batched JSON (optimized)
- POST `/api/steroids-settings` → applies + saves

### 3.4 `stats-editor/index.html` (`/stats-editor`)
- Load `reading_stats.json` via `/api/reading-stats`
- Edit: daily goals, streak, per-book times, achievements
- Save → streams back to device

## 4. API Optimization (Settings API)

### Before: 50s Response
```cpp
// Old: individual I18N resolution per string, no batching
for (setting : allSettings) {
    json[setting.key] = tr(setting.i18nKey);  // 1000+ tr() calls
}
```

### After: <1s Response
```cpp
// Batched JSON output + pre-resolved I18N
JsonDocument doc;
preResolveI18nStrings();  // Single pass
serializeJson(doc, response);  // One write
```
